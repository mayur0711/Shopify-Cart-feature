# 🛒 Shopify Cart Feature

A custom Shopify Cart Feature built using Shopify Liquid, JavaScript, HTML, and CSS. This project enhances the default Shopify cart experience with dynamic cart updates, cart drawer functionality, quantity management, responsive design, and seamless user interactions.

---

## 📌 Project Overview

This project demonstrates the implementation of Shopify's cart system with modern eCommerce functionality, including:

- Cart Drawer
- Cart Page
- AJAX Cart Updates
- Quantity Controls
- Remove Cart Items
- Real-Time Cart Refresh
- Responsive UI
- Shopify Dawn Theme Integration

The goal of this project is to create a smooth shopping experience without unnecessary page reloads.

## 💻 Installation

### Clone Repository

```bash
git clone https://github.com/mayur0711/Shopify-Cart-feature.git
```

### Navigate to Project

```bash
cd Shopify-Cart-feature
```

### Upload to Shopify Theme

1. Open Shopify Admin
2. Go to **Online Store → Themes**
3. Click **Edit Code**
4. Upload the project files into your theme
